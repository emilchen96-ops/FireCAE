## 当前判断

FireCAE 已经能完成七个选定教程的“空工程前处理 → FDS 输入 → CPU/MPI 求解 → Smokeview/原生后处理 → 对比报告”技术闭环，但不能据此宣称已完整复制 PyroSim。

要达到产品级同等体验，优先级最高的是：

1. 完成 R01 多选表面、纹理继承、墙交点编辑和高级几何修复，再把通用 namelist 编辑器逐步替换为材料、反应、火源、控制、HVAC 和输出的专用表单；
2. 完成复杂 IFC 属性/材料、GLB 多材质纹理以及 FBX/DAE 合法导入链；
3. 增强内嵌原生场结果解码和 GPU 体渲染；
4. 使用合法 PyroSim 独立工程和结果完成三方对比；
5. 在独立 Windows 机器上执行便携包/安装器、GPU/驱动和高 DPI 验收。
