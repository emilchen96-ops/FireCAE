## 3. 外部进程

循环测试在开始前记录已有 `fds`、`fds_openmp`、`mpiexec` 和 `smokeview` PID，只判断本轮新增进程是否回收。测试期间没有新增残留进程。本机存在一个测试开始前就已运行、权限归属不同的 Smokeview PID 13888；它被作为基线保留，没有将其误杀，也没有把它计为 FireCAE 残留。

## 4. 主线程响应

IFC 生产向导使用后台任务、进度和取消；求解器使用任务管理器和外部进程；结果刷新/播放使用事件循环，不以阻塞等待冻结主窗口。13 MB Clinic IFC 完整导入、转换和求解专项在三种构建中均通过。

## 5. 未覆盖环境

本报告只覆盖当前 Windows 主机。第二台物理机、多显卡/多 DPI 组合、休眠恢复、长时间网络盘工程和数字签名安装器仍需现场验收。
