# FireCAE 界面收敛与 Smokeview 工作流修复报告

日期：2026-08-30  
版本：0.3.0（本地 Release 构建）

## 结论

本轮已将近期记录的界面与工作流问题逐项落地。FireCAE 现在启动后直接进入三维建模工作区；正式后处理入口统一为嵌入式 Smokeview；旧的二维独立页、原生结果页及重复动画菜单已从正常界面隐藏。

Release 全量测试结果：`24/24 passed`，总耗时约 `330.24 s`。便携包隐藏启动自检通过。

## 已完成项

1. 启动页不再默认打开，“文件”菜单也不再显示启动页入口；启动后直接显示空工程三维建模界面。
2. “仅显示此对象”改为临时隔离，不写入工程对象的 `visible` 状态；工具栏、视图菜单和模型树右键均可一键“退出隔离/显示全部对象”。退出隔离会恢复用户原先主动隐藏的对象。
3. 串行 CPU 模式优先使用 `fds_openmp.exe` 加 `OMP_NUM_THREADS=1`，避免启动 MPI 主程序 `fds.exe` 引发重复 Windows 防火墙联网确认；旧 FDS 安装缺少 OpenMP 程序时仍会回退到 `fds.exe`。显式 MPI 模式保持不变。
4. “尚未加载结果算例。”修改为“尚未加载仿真结果。”；结果已加载时提示用户在 Smokeview 中打开。
5. 仿真任务中心只显示一个“运行日志”页；原始 stdout/stderr 仍在内部控件中保留，供诊断和自动化测试读取。
6. 原生结果器内部术语已澄清为“几何来源 / FireCAE 可编辑几何 / FDS 输入几何 / FDS 网格吸附预览 / CAD/IFC 参考几何”。该结果器目前不在正式界面显示。
7. 嵌入式 Smokeview 增加“放大”“缩小”按钮，并将键盘/鼠标输入发送到真实 Smokeview 子窗口；播放、暂停、首帧、上一帧、下一帧仍保留。
8. 独立“二维平面”标签页已隐藏。用户可在模型树或三维视图中选中单一平面对象，右键“正视此平面”；软件保存原视角、切换正交投影并适配选中对象，之后可点“恢复视角”。楼层背景图也可在三维顶视状态下使用。
9. OCCT 选择高亮加强：选中对象使用高对比橙色和粗边界，悬停对象使用亮黄色边界。
10. 结果菜单删除“原生结果查看器、烟气/火焰动画、切片动画、粒子动画”等重复入口，只保留一个“在 Smokeview 中打开”作为可视化入口；结果对比、重新加载、关闭和 Smokeview 配置仍保留。
11. 打开结果、任务中心打开结果、求解完成后自动打开结果，均统一进入嵌入式 Smokeview 标准模式。
12. 原生后处理代码和旧二维视图代码均保留用于兼容和后续开发，但不会干扰当前正式产品界面。

## 建议手动检查顺序

1. 启动软件，确认直接进入三维建模界面。
2. 打开示例，选中一个对象并执行“仅显示此对象”；再点工具栏“退出隔离”，确认恢复原显示状态。
3. 选中墙、楼板、VENT 或切片平面，右键“正视此平面”；点击“恢复视角”。
4. 运行最小算例，确认串行命令预览使用 `fds_openmp.exe` 且线程数为 1，并观察不再弹出 `fds.exe` 的 Windows 防火墙确认。
5. 打开求解结果，确认直接进入嵌入式 Smokeview，并验证播放、暂停、放大和缩小按钮。
