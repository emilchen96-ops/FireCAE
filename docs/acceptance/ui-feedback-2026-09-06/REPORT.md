### 附着功能的正确理解

- **不附着对象**：按“位置与尺寸”创建燃烧通风口 VENT，不自动创建障碍物基座；需将它放在合适的固体表面或网格边界。
- **已有通风口 VENT**：替换该通风口的表面引用，保留已有空间定义，不额外新建 VENT。
- **已有障碍物 OBST**：指定整体默认表面，不等于仅选择顶面；已有单面赋值保留。仅顶面燃烧应使用单独的平面燃烧通风口。
- **几何对象**：修改默认表面；仍需生成或更新其 FDS 几何转换后再求解。

这次没有新增自动选面、自动基座、任意方向燃烧面绘制或自动几何转换，也没有通过翻译改变火源物理参数。

## 建议你手动复查

1. 保存当前工程，退出旧 Debug 窗口；打开本报告的 Release 入口，确认语言选择为简体中文。
2. 在测试工程中修改或复制一个对象，再点“新建工程”或“打开工程”。应出现中文正文和三个中文按钮；先点“取消”，检查原工程还在。
3. 找到被通风口引用的表面，尝试删除。应出现引用者列表。选择一行后点“定位引用对象”，应定位到对应对象；表面和引用关系仍保留。不要为了测试随意删除正式工程数据。
4. 打开火源向导，分别选“不附着对象”、已有 VENT、已有 OBST。核对类型、当前表面和作用范围说明；附着已有对象时，位置参数不应允许误改。此步可点“取消”，无需提交新火源。
5. 在时间与热释放率预览页，开关“创建独立增长曲线记录”。检查坐标轴和摘要为中文、曲线含义随选项变化；切换语言后自定义名称及已选宿主不应变化。
