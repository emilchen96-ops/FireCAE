# FireCAE A11 求解与任务中心验收报告

日期：2026-08-29

## 已验证能力

- 串行 FDS 运行、标准输出和错误输出采集、进度和 ETA；
- CPU/MPI 运行，使用 8 个相邻网格和 8 个 MPI 进程完成真实求解；
- 运行中主动停止；
- 无效 FDS 参数的失败诊断；
- 多任务队列、取消和重试；
- 每个任务独立工作目录，完成后自动发现 `.smv` 结果；
- 当前场景的 CHID、输出目录、串行/MPI 后端和进程数进入实际运行路径。

## 自动验收

`FireCAEFdsRunnerTests` 使用项目捆绑的 FDS/MPI 运行时验证：

1. `solver_serial.fds` 串行正常结束；
2. `solver_mpi8.fds` 以 8 个 MPI 进程正常结束；
3. `solver_stop.fds` 在求解活动期间可停止；
4. `solver_failure.fds` 返回具体的非法参数诊断；
5. 队列中的任务可取消、失败任务可重试。

GUI 任务中心显示状态、开始时间、进度、已用时间和预计剩余时间。

## 外部后端边界

本阶段启用本机串行和本机 CPU/MPI。远程集群按钮未伪装为已完成；只有配置实际 SSH/调度器后才应显示并验收远程提交。
