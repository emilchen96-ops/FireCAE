# FireCAE A12 场景与批量计算验收报告

日期：2026-08-29

## 数据模型

- `FcProject` 持有唯一场景集合和活动/默认场景 UUID；
- 场景仅保存差异：CHID、输出目录、后端、进程数、禁用对象 UUID 和参数覆盖；
- 基础 `FcDocument/FcObject` 树不复制；
- 场景引用继续使用 UUID，不以名称作为唯一键；
- 工程格式升级到版本 3，旧工程无场景字段时自动创建默认场景。

## GUI 和运行链路

- 场景管理器支持新建、复制、重命名、删除、设为默认和比较；
- 对象树可按 UUID 启用/禁用对象；
- 参数覆盖表支持原始值和对象引用；
- 参数研究可由一到两个变量生成笛卡尔积场景；
- 切换场景会同步模型树、三维显示和 FDS 导出；
- “运行全部场景”创建独立目录和 FDS 文件，失败场景不阻断后续任务。

## 自动验收

- `FireCAEA12ScenarioUiTests`：从 GUI 修改默认场景 CHID，再导出并校验 FDS；
- `FireCAEFdsModelTests`：创建、复制、禁用对象、覆盖网格参数、保存、重开并验证差异模型未复制基础对象树；
